- **No-bash persona →** slash command works directly:
  `/agent <persona> "review lux/native-cli/tests/receipt_verifier.rs"`
- **bash persona →** the Agent tool with a tools-override (drop bash; `/agent` cannot pass tools and
  would hit `bash-project-settings-denied` from the workspace cwd):

Inspect each: `agent_team run_status <runId> waitSeconds 30 preview true` → expect `terminal=true`,
`status=succeeded`.
